## Kế hoạch: Admin Dashboard Dark/Glassmorphism + Canvas Particles + Theme Color Picker

**Phạm vi (đã chốt):** Chỉ khu vực Admin. Toàn bộ UI primitives của app đều đọc CSS variables, nên phần lớn thay đổi tập trung vào **scope `.coreform-admin`** (CSS) + **nhánh admin của `AppLayout`** (JSX) + vài component mới. **Màn User 100% giữ nguyên** vì không có class `.coreform-admin` làm ancestor.

**Stats:** giữ số liệu thật (Tổng ND, ND mới hôm nay, Thực đơn, Kế hoạch) + 2 charts tăng trưởng/phân bố mục tiêu. **DataTable:** nâng cấp UserList hiện có (data thật).

---

### 1. Theme Store — `src/stores/admin-theme.store.ts` (MỚI)
- Zustand + `persist` (localStorage key `admin-theme`), dùng `createSelectors` đúng convention hiện tại.
- State: `accent` (hex string, default `#6366f1` indigo), `themeName` (string).
- Action: `setAccent(hex, name)` — viết vào CSS var `--accent` + các biến phái sinh (`--accent-hover`, `--accent-rgb` để dùng `rgba()` cho glass/border-glow) trên `document.documentElement`.
- Hook `useAdminThemeAccent()` trả về accent hiện tại để canvas + charts đọc.

### 2. `AdminParticleCanvas` — `src/components/shared/coreform/AdminParticleCanvas.tsx` (MỚI)
- `<canvas fixed inset-0 -z-10>` chạy `requestAnimationFrame`.
- Constellation network: ~80 hạt di chuyển, nối đường khi gần nhau (opacity theo khoảng cách).
- Tương tác chuột: hạt **né** con trỏ trong bán kính (repel) — hiệu ứng sống động.
- Màu hạt + đường nối = `accent` từ theme store (đọc qua CSS var `--accent`), cập nhật live khi đổi màu.
- `prefers-reduced-motion` → tắt animation, chỉ vẽ tĩnh. Responsive `devicePixelRatio`. Pause khi tab ẩn (visibilitychange).

### 3. `ThemeColorCustomizer` — `src/components/shared/coreform/ThemeColorCustomizer.tsx` (MỚI)
- Popover trên Top Header (icon `Palette`).
- 4 preset swatch: **Cyber Purple** `#8b5cf6`, **Emerald** `#10b981`, **Neon Blue** `#2563eb`, **Sunset Orange** `#f97316`.
- `<input type="color">` tùy chỉnh.
- Gọi `setAccent` → đổi tức thì toàn hệ thống (button, active menu, border glow, chart, canvas).

### 4. Nhánh admin `AppLayout.tsx` (REWRITE lines ~344-487)
Giữ nguyên logic (auth, notifications, navigation handlers, `adminNavigationGroups`), chỉ đổi JSX sang dark glass:
- Root: `coreform-admin` + thêm `<AdminParticleCanvas />` + `<ThemeColorCustomizer />`.
- Sidebar: thu gọn/mở rộng (toggle `collapsed` state, `w-64`↔`w-20`), glass `bg-slate-900/60 backdrop-blur-xl border-white/10`, active item dùng `--accent` + glow.
- Top header: glass `bg-slate-900/50 backdrop-blur-xl`, thêm thanh search (icon Search) + `ThemeColorCustomizer` + Bell notifications (giữ nguyên Popover logic) + avatar dropdown (giữ nguyên).
- Mobile: thêm `<Sheet>` cho sidebar (admin hiện thiếu responsive).

### 5. `.coreform-admin` scope trong `dashboard.css` (REWRITE lines ~113-330)
- Token nền: `--background: #0f172a` (slate-900), `--card: rgba(15,23,42,.6)` (glass), `--foreground: #f1f5f9`, `--border: rgba(255,255,255,.08)`.
- Thêm `--accent`, `--accent-hover`, `--accent-rgb` làm nguồn cho: primary, ring, button-primary, chart, selection.
- Glass utilities: `.coreform-admin [data-slot="card"]` → `backdrop-blur-xl bg-white/[0.04] border-white/10 shadow-2xl`, hover glow dùng accent.
- Sidebar/header/input/badge/data-table: tất cả dark qua scope CSS (KHÔNG đụng component dùng chung → user an toàn).
- Giữ pattern neutralize hex hardcode (DishCard/MenuCard) nhưng chuyển sang dark-friendly.

### 6. Stats + Charts (`AdminDashboard.tsx`, `StatsCards.tsx`, `UserGrowthChart.tsx`, `UserGoalChart.tsx`)
- Heading màu sáng, card kế thừa glass tự động.
- Charts: hardcode `#2563eb` → đọc accent từ `useAdminThemeAccent()` (đổi màu theo theme picker).

### 7. DataTable/UserList
- Không sửa component. Style dark qua `.coreform-admin` scope CSS (header bg, row hover, border, pagination).

### 8. Verify
- `npx tsc --noEmit` + `npm run build`. Chạy dev, kiểm /admin/dashboard, /admin/users, đổi 4 preset + custom color, kiểm canvas tương tác, kiểm màn user còn nguyên.
